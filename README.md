# Куфический шрифт чисел

`kufi.ttf` — шрифт, в котором обычные цифры превращаются в
каллиграфическое написание года, как на омейядских дирхемах. Печатаете
`132` — получаете مية سلس ملد. Текст остаётся текстом: ищется, правится,
меняет кегль, вшивается в PDF.

Формы сняты с самих монет. Диапазон **1–299**, версия **1.100**.

## Открыть

**[Год на монете](https://boris3diamond-source.github.io/kufi-numerals/)** —
введите число, посмотрите написание, скачайте шрифт или SVG отдельного числа.
Там же — подробная инструкция по установке на Mac.

* [Лист-образец](https://boris3diamond-source.github.io/kufi-numerals/specimen.html)
  — все детали, из которых собираются числа, и проверка постоянства штриха
* [Шпаргалка](https://boris3diamond-source.github.io/kufi-numerals/cheatsheet.pdf)
  — закладка-ключ к чтению даты на монете, 75 × 210 мм
* [Скачать шрифт](https://boris3diamond-source.github.io/kufi-numerals/kufi.ttf)
  напрямую

## Установка коротко

Двойной щелчок по `kufi.ttf` → «Установить» → перезапустить программу,
в которой набираете → выбрать гарнитуру «Kufi» и набрать число
обычными цифрами.

**В Microsoft Word включите лигатуры:** «Формат» → «Шрифт…» → «Дополнительно» →
«Лигатуры» → «Только стандартные». Без этого вы увидите обычные цифры — Word
единственный не включает их сам.

**Числа больше 299 набирать нельзя.** Ошибки не будет: `305` молча покажет
«тридцать» и «пять» рядом, то есть чужое число.
